# TIL

오늘 배운, 알게 된, 학습한 내용을 내 언어로 정리하는 저장소입니다.

## 기록 원칙

- 배운 내용만 나열하지 않고 `막힌 점 - 확인 - 해결 - 다음 행동`을 남깁니다.
- 복사한 설명보다 스스로 재현할 수 있는 예제와 설명을 우선합니다.
- 코드, 문서, 강의 등 근거가 있으면 링크를 남깁니다.
- 발행 전에 비밀 값과 개인정보가 포함되지 않았는지 확인합니다.

`TEMPLATE.md`를 복사해 작성합니다. 폴더는 일단 `YYYY/MM/`를 기본으로 사용하되, 주제별 기록이 더 자연스러워지면 구조를 변경할 수 있습니다.
